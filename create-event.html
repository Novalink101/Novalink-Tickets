Paste one Yoco Payment Link for each tier. Buyers pay on this link.

How to get your Yoco link
Open the Yoco app → Sell → Payment Links → New link. Set the amount to match your tier price, then copy the link and paste it here.

Tip: set a reference field on the Yoco link so buyers can paste their Novalink reference when paying.
You can skip this step
If you don't have your Yoco links ready yet, leave them blank. Just submit the event — we'll help you attach the links before it goes live.
