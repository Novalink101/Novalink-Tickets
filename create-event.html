Location — Paste Any Map Link

Copy the Share → Copy link URL from any map app and paste it above. We'll detect the provider and show an inline preview.

  1. Google Maps — Search the venue → tap Share → Copy link
  2. Apple Maps — Tap the venue → Share → Copy
  3. OpenStreetMap — Right‑click the map → Copy link (URL will include #map=…)
  4. Bing Maps — Right‑click → Copy link (URL will include ?cp=lat~lng)
  5. Waze — Tap the venue → Share → Copy link
  6. Anywhere else — any URL containing lat,lng coordinates will work too

Short links (like maps.app.goo.gl/…) are saved, but for an inline preview use the full URL that contains the coordinates.
